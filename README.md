# A/E KALEM

A modern, rebranded canvas whiteboard. Built as a single-file HTML app with drawing tools, themes, shapes, pan/zoom, and project save/load.

[![Netlify Status](https://api.netlify.com/api/v1/badges/7dd5bb6c-4836-4a64-bee4-557e617b3a53/deploy-status)](https://app.netlify.com/projects/aekalem/deploys)

## Features

- **Drawing Tools**: Pen and Eraser with adjustable thickness
- **Shape Tools**: Line, Rectangle, Circle, Arrow
- **Colors**: Predefined colors, custom color picker, and automatic pen color switching on theme change (with manual override)
- **Themes**: Dark/Light mode with automatic pen color adjustment
- **Background**: Custom background color picker, plus optional line/grid patterns
- **Canvas Navigation**: Pan (Middle mouse/Ctrl+Drag) and Zoom (Mouse wheel), with reset view
- **History**: Undo/Redo support
- **Save/Load**: Save as PNG, Save as JSON (editable projects), Load JSON
- **Responsive**: Works on desktop and mobile
- **Branding**: A/E KALEM with developer link
